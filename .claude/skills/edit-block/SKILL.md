# Монтаж блока

Один блок — одна сессия. Контекст держать маленьким: см. «Студия монтажа: правила для агента» в `CLAUDE.md`.

## Новый блок

1. Прочитать: `studio/SCENES.md`, страницу видео `docs/wiki/videos/NNN-*.md` (раздел «Монтаж» и «Визуал»), и **только свой блок** сценария — найти строки (`grep -n "^## Блок" docs/wiki/videos/NNN-*-script.md`) и прочитать их `sed -n`.
2. Файл `studio/episodes/NNN/blocks/NN-slug.json` (NN — номер блока с нулём, slug — латиница). Формат и сцены — в `studio/SCENES.md`; первый раз — подсмотреть `studio/episodes/000/blocks/`.
   - id: `L<блок><nn>`, `S<блок><nn>`, `O<блок><nn>`; speaker — имена из `edit.json → voices`
   - каждая реплика — одна сцена или несколько; сцены привязаны якорями (`L201`, `L201:end`, `L201+1.5`)
   - чего нет — `placeholder` с понятной подписью, что найти/снять
   - ассеты: файл в `studio/public/episodes/NNN/img|video|music/`, запись с `license` и `url` (`npm run find-assets -- --get "File:…" --ep NNN --key имя` печатает готовую)
   - главы: `chapters` на первой реплике блока
3. Из `studio/`:
   - `npm run tts:placeholder -- NNN` (или `tts:elevenlabs`, если голоса выбраны — сначала `--dry`)
   - `npm run timeline -- NNN`
   - `npm run check -- NNN N` — исправить всё, что не «заглушки, ожидаемо»
   - `npm run render:block -- NNN N` → `npm run qa -- NNN N`, читать только `out/NNN-bN-qa.md`; картинки (`out/NNN-bN-sheet.jpg`) — только при находках или для нового типа сцены
4. Статус блока — в таблицу «Монтаж» страницы видео. Владельцу: что в блоке, что осталось заглушками, как смотреть (`npm run studio`, композиция `ENNN`).

## Правки по заметкам

1. Таймкоды владельца → `npm run where -- NNN 2:15 3:40` (блок, сцена, реплика).
2. Точечные Edit в JSON блока, без перезаписи файла.
3. `timeline` → `check` → при необходимости `render:block`/`qa`.
4. Если заметка — общее правило («заставка всегда должна доигрывать»), записать решение (процесс 4 в `CLAUDE.md`): `docs/raw/notes/` → `docs/wiki/content/editing-studio.md` → при возможности проверка в `studio/scripts/check.ts`.

## Конец блока

Блок принят («ок, дальше») — следующий блок не начинать здесь: предложить новую сессию с брифом (номер видео и блока, где сценарий, что уже сделано, чем проверять).
