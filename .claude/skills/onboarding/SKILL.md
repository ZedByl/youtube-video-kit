# Онбординг канала

Процесс 0 из `CLAUDE.md`. Цель — чтобы следующая сессия агента знала канал по репозиторию, без пересказа.

## Шаги

1. Прочитать `CLAUDE.md`, `docs/wiki/identity/channel-concept.md`, `docs/raw/notes/2026-11-15-kit-defaults.md`.
2. Расспросить владельца — короткими порциями по 3–4 вопроса, не анкетой на 20 пунктов:
   - О чём канал одним предложением, для кого (страна, возраст, интересы), чем отличается от других
   - Название, @handle, язык видео
   - Длина видео (окно), частота, Shorts — да/нет
   - Подача: один ведущий / два / закадровый голос; свой голос или синтез; имена и зоны ведущих; обращение к зрителю
   - Тон: каким канал должен быть и каким — никогда
   - Рубрики (2–6)
   - 3–10 каналов-ориентиров (конкуренты, доноры на других языках, похожий формат)
   - 5–10 первых идей тем
   - Есть ли бренд: цвета, шрифты, логотип (если нет — нейтральная тема остаётся)
3. Ответы — дословно в `docs/raw/notes/YYYY-MM-DD-onboarding.md` (шаблон `docs/templates/raw-template.md`).
4. Заполнить и перевести в `active`, где хватает данных:
   - `docs/wiki/identity/channel-concept.md` (убрать плашку-предупреждение)
   - `docs/wiki/audience/<сегмент>.md`, `docs/wiki/positioning/<ниша>.md` (новые страницы по `docs/templates/wiki-template.md`)
   - `docs/wiki/competitors/benchmark-channels.md`
   - `docs/wiki/topics/topic-bank.md` — таблица на каждую рубрику, первые идеи с оценкой
5. `studio/channel.json`: `name`, `language` (код ISO 639-1, его же ждёт ElevenLabs), `locale` (формат чисел, например `ru-RU`, `de-DE`), `quotes` (кавычки языка: «», „“, “”), тексты `subscribe` и `labels` — на языке видео.
6. Голоса: в `studio/episodes/000/edit.json` → `voices` поставить имена ведущих и голоса macOS для заглушек (`say -v '?'` — список; для русского есть Milena, Yuri). Пример-эпизод можно оставить как справочник или удалить по желанию владельца.
7. Если владелец дал бренд — цвета в `design-system/tokens.json` (имена токенов не менять), шрифты в `studio/src/theme.ts`; проверить `cd studio && npm run typecheck`.
8. Пройти стартовые правила в `docs/wiki/content/` против ответов: что противоречит каналу (например, формат двух голосов при одном ведущем, окно длины) — поправить со ссылкой на онбординг.
9. Если подключается n8n — каналы-ориентиры в `automation/n8n/channels.json` и в ноду `Channels list` в `automation/n8n/trends.json`.
10. Обновить `docs/wiki/index.md`, запись `ingest` в `docs/wiki/log.md`.
11. В конце — коротко владельцу: что заполнено, что осталось пустым, и предложить первую тему из банка для `/new-video`.
