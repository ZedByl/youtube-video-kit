# Новое видео

Процесс 1b из `CLAUDE.md`, шаги 1–5. Монтаж блоков — отдельно, скилл `edit-block`, по одному блоку на сессию.

## Шаги

1. Номер: следующий за последним в `docs/wiki/videos/` (первое видео — `001`). Slug — латиница, kebab-case.
2. Тема в `docs/wiki/topics/topic-bank.md` → статус `в работе`.
3. Страница `docs/wiki/videos/NNN-slug.md` по `docs/templates/video-template.md`: тема, угол (вопрос видео), 3–5 заголовков, идея превью. Если упаковка не придумывается — сказать владельцу, что тема слабая, и предложить вернуть её в банк.
4. Досье `docs/wiki/research/slug.md` по `docs/templates/dossier-template.md`. Найденное в сети — сначала `docs/raw/references/YYYY-MM-DD-slug-<что>.md` (URL, дата, выдержки своими словами), потом факт в досье со ссылкой. Спорное — ⚠️.
5. Перед сценарием — разделы 1–2 `docs/wiki/content/script-checklist.md` и формат из `docs/wiki/identity/channel-concept.md` (длина, голоса, обращение).
6. Сценарий — `docs/wiki/videos/NNN-slug-script.md`: блоки `## Блок N — название (≈ таймкод)`, реплики `ИМЯ: текст`, разметка `[VISUAL: …]`, `(⏸)`, `[M: …]`, `[SFX: …]`. Каждый блок станет `studio/episodes/NNN/blocks/NN-slug.json`.
7. После черновика — памятка целиком: подсчёт слов по блокам (~140 слов/мин), оценка длины, таблица фактов. В «Заметках» сценария — только отступления от памятки и причина.
8. Визуал: таблица «Визуал и лицензии» в странице видео, кандидаты — `cd studio && npm run find-assets -- "<что нужно>" --q "<запрос>"`.
9. Монтажная заготовка: `studio/episodes/NNN/edit.json` — копия `studio/episodes/000/edit.json` с новыми `id`, `title`, голосами; `lines`/`scenes` пустые. В страницу видео — копия чеклиста публикации из `docs/wiki/content/publish-checklist.md`.
10. `docs/wiki/index.md` (новые страницы), запись в `docs/wiki/log.md`.
11. Владельцу: ссылка на сценарий для вычитки и предложение начать монтаж блока 0 в новой сессии (`/edit-block NNN 0`).
