# YouTube Video Kit — канал, который ведёт агент

Шаблон репозитория для YouTube-канала, где ИИ-агент (Claude Code, Codex, Cursor) работает вместе с вами: ищет темы, собирает досье с источниками, пишет черновики сценариев, **монтирует видео кодом** и ведёт всю документацию канала. Вы выбираете темы, вычитываете, смотрите черновой монтаж и даёте заметки.

Структура и правила вынесены из работающего документального канала. Стилистики и контента того канала здесь нет: только каркас, процессы и нейтральная студия.

## Что внутри

```
.
├── CLAUDE.md               правила и процессы для агента (главный файл)
├── AGENTS.md               то же для Codex / Cursor — ссылка на CLAUDE.md
├── docs/                   база знаний (Obsidian vault)
│   ├── raw/                исходники: решения, ресёрч, статистика — не редактируются
│   ├── wiki/               страницы, которые ведёт агент: концепция, банк тем, досье, журнал видео, правила
│   └── templates/          шаблоны страниц видео, досье, исходников
├── studio/                 студия монтажа на Remotion
│   ├── channel.json        имя канала, язык, тексты плашек
│   ├── SCENES.md           шпаргалка по сценам и командам
│   └── episodes/000/       пример видео — собирается без единого чужого файла
├── design-system/          цвета и шрифты (нейтральная заглушка — замените на свои)
├── automation/n8n/         сбор статистики и трендов по расписанию (по желанию)
└── .claude/skills/         процедуры агента: onboarding, new-video, edit-block, wiki-lint
```

## Как это работает

1. **Онбординг.** Агент расспрашивает о канале и заполняет концепцию, аудиторию, конкурентов, первые темы, язык и тексты студии.
2. **Тема → досье → сценарий.** Тема из банка, 3–5 заголовков и идея превью, досье (каждый факт со ссылкой), сценарий по блокам с разметкой визуала.
3. **Монтаж по блокам.** Агент переводит блок сценария в JSON: реплики, сцены (фото с Ken Burns, карты, таймлайны, счётчики, цитаты, схемы связей…), музыку, плашки. Скрипты озвучивают, считают тайминг, проверяют лимиты текста, лицензии, повторы и статику, рендерят блок и проверяют кадры.
4. **Ваши заметки.** Смотрите в Remotion Studio, пишете «на 1:20 фото висит долго» — агент находит сцену по таймкоду и правит.
5. **Публикация.** Финальный рендер, громкость под YouTube, субтитры, главы, описание с атрибуцией, превью, чеклист публикации.
6. **Аналитика.** Метрики через 48 часов и 7 дней, выводы — в правила сценариев и банк тем.

Всё, что решено, записывается: решения владельца — в `docs/raw/notes/`, правила — в `docs/wiki/`, каждая операция — в `docs/wiki/log.md`. Следующая сессия агента знает канал по репозиторию.

## Быстрый старт

Нужно: macOS или Linux, [Node.js](https://nodejs.org) 20+, ffmpeg (`brew install ffmpeg`), Claude Code или другой агент. Для заметок удобно открыть `docs/` в [Obsidian](https://obsidian.md).

```bash
cd studio
npm install
npm run setup:browser
```

Пример видео:

```bash
npm run tts:placeholder -- 000
```

```bash
npm run timeline -- 000
```

```bash
npm run studio
```

Голоса-заглушки работают на macOS (команда `say`). На Linux пропустите этот шаг: длительность реплик оценится по тексту, видео соберётся без звука.

Дальше откройте агента в корне репозитория и скажите: **«Давай настроим репозиторий под мой канал»** — он запустит онбординг.

## Что понадобится по ходу

- **Озвучка:** ElevenLabs (ключ в `studio/.env`, см. `.env.example`) или свой голос — wav-файл на реплику в `studio/public/episodes/NNN/voice/`
- **Визуал:** свои съёмки и открытые лицензии — поиск по Wikimedia Commons встроен (`npm run find-assets`)
- **По желанию:** [ollama](https://ollama.com) для локальной проверки кадров, n8n для статистики и трендов (`automation/n8n/README.md`)
