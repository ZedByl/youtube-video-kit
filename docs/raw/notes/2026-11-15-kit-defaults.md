# Стартовые правила шаблона

Это исходник для стартовых страниц `docs/wiki/content/`. Правила вынесены из живого канала: документальные истории 12–23 минуты, синтетические голоса, монтаж кодом на Remotion, визуал из открытых архивов. Для другого канала часть правил может не подойти — их правят по процессу «Правка правил» в `CLAUDE.md` и записывают решение отдельным raw-файлом.

## Процесс

- Еженедельный цикл: тренды → тема и угол → досье → сценарий → визуал → озвучка → монтаж → упаковка → публикация → аналитика 48ч/7д
- Тема без 3–5 заголовков и идеи превью — слабая, возвращается в банк
- Каждый факт — из досье со ссылкой на источник; спорное помечается ⚠️ и проверяется человеком
- Роли: агент — черновики, ресёрч, монтаж JSON, описания, отчёты; человек — выбор темы, вычитка, съёмка, финальный отбор, режиссёрские заметки

## Сценарий и удержание

- Первые слова — событие (время, место), без приветствия; обещание заголовка и превью — в первые 10 секунд
- Один реальный герой лучше панорамы; загадку назвать, ответ не давать до кульминации
- Каждые 3–4 минуты — поворот или новая петля; каждый блок заканчивается недосказанностью
- После кульминации нужна новая петля — иначе зрители уходят
- 1–3 вопроса к зрителю за видео (ответ одним словом или короткой историей); не в хуке и не в кульминации
- Финал без дат и дней недели в анонсе следующего выпуска: день выхода может сдвинуться
- Длина — сколько требует история, без растягивания: сокращать текст, а не паузы. Деталь остаётся, только если раскрывает героя, усиливает конфликт, приближает разгадку или объясняет главную мысль
- Подсчёт: ~140 слов в минуту речи

## Монтаж (Remotion)

- Монтаж по блокам сценария: один блок — один JSON — одна сессия агента (экономия контекста)
- Агент не читает timeline.json и логи, а работает через короткие сводки: check, where, qa
- Заставка доигрывает ~4 с без речи; плашки с именами — не поверх заставки
- Графика с цифрами — без анимированного наезда: цифры дрожат. Ken Burns по фото допустим
- Динамика: ассет ≤ 2 показов на видео (герой ≤ 3), не в соседних сценах; сцена > 15 с — только со сменой внутри; средняя сцена 6–7 с; текстовая графика ≤ 35 % хронометража; хроника — 10 % и больше. Видео без этих правил владелец назвал скучным
- Громкость финала — −14 LUFS / −1 dBTP

## Визуал и лицензии

- Свои съёмки + открытые лицензии (Public domain, CC0, CC BY, CC BY-SA); у каждого ассета источник и лицензия
- Чужие видео и фото без разрешения — нельзя (страйки)
- Атрибуция — в описании (сводно по лицензиям) и построчно в закреплённом комментарии
- AI-генерация не для реальных предметов и людей: искажает детали

## Упаковка и публикация

- Заголовок ≤ 60 знаков: интрига + конкретика (год, цифра, человек), без обещаний, которых нет в видео
- Превью: одна эмоция или событие, одна цифра и 2–4 слова; читается при ширине 240 px; не повторяет заголовок
- Описание: первые ~150 знаков — место, эпоха, имя; главы (первая 0:00, 8–12 штук); источники; 3 хэштега; атрибуция
- Синтетические голоса — отметка «изменённый или синтетический контент» при загрузке
- Сначала загрузка «по ссылке» — проверить обработку HD и Content ID
