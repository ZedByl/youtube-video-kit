# Каталог источников

Куда идти за фактами и визуалом по нише канала. Пополняется по ходу досье: нашёлся хороший архив, база или книга — строка сюда.

## Правила ресёрча

- Каждый факт в досье — со ссылкой на источник; найденная страница сохраняется в `raw/references/YYYY-MM-DD-<тема>.md` (что нашли, URL, дата)
- Два независимых источника для ключевых фактов сценария; спорное — ⚠️ в досье с версиями
- Первичные источники (документы, мемуары, архивы, научные статьи) важнее пересказов
- Википедия — точка входа и список литературы, но не единственный источник

- Встроенный веб-поиск агента; Bright Data CLI (`bdata`), если подключён
- Wikimedia Commons API — лицензии и автор берутся прямо из метаданных файла
