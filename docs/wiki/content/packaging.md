# Упаковка: превью, заголовок, описание

Стартовые правила — [[raw/notes/2026-11-15-kit-defaults]].

## Превью

- Одна эмоция или одно событие, минимум текста: одна цифра (год, сумма) и строка в 2–4 слова
- Делается в студии: шаблон `studio/src/Thumbnail.tsx` (1280×720) берёт цвета и шрифты из `design-system/tokens.json`, у всех превью канала один почерк, лицензии фото уже известны. Два режима: одно фото с текстом слева или две половины «тогда ↔ сейчас». Варианты — `studio/episodes/NNN/thumbnails.json`, рендер — `npx remotion still TNNN-A out/thumb-NNN-a.png`
- AI-генераторы — не для реальных предметов и людей: искажают детали. Допустимы для фона или текстуры
- Проверка: превью, уменьшенное до 240 px (мобильная лента), читается
- Превью не повторяет слова заголовка, а дополняет их
- A/B: встроенный «Test & Compare» YouTube, до 3 вариантов

## Заголовок

- Интрига плюс конкретика (год, цифра, человек), ≤ 60 знаков, без обещаний, которых видео не выполняет
- 3–5 вариантов набрасываются ещё на этапе выбора темы; не придумывается — тема слабая ([[wiki/content/production-pipeline]])
- Перед публикацией — основной и запасной для теста; если тест заголовков недоступен — сменить вручную через 48 ч по CTR

## Описание

Собирается скриптом `npm run meta -- NNN` из ручного файла `studio/episodes/NNN/description.md` (секции `## intro`, `## sources`, `## hashtags`, `## pinned`) и `timeline.json`. Подписи (Chapters, IMAGE CREDITS…) — `studio/channel.json → labels`, на языке канала. Порядок:

1. Шапка — 3–4 абзаца пересказа. Первые ~150 знаков видны до «ещё» и идут в поиск: место, эпоха, ключевое имя
2. Главы между линиями `━━━━━━━━━━━━━━━`: первая 0:00, каждая ≥ 10 с, 8–12 штук по блокам сценария (поле `chapters` в блоках)
3. Источники одной строкой — из досье
4. Три хэштега (YouTube показывает их над заголовком)
5. Атрибуция — авторы, сгруппированные по лицензии, и ссылки на тексты лицензий ([[wiki/content/visual-licensing-policy]])
6. Строка «построчная атрибуция — в закреплённом комментарии»

Закреплённый комментарий (`pinned-comment-<lang>.txt`) — вопрос к зрителям и построчная атрибуция каждого кадра без ссылок (комментарий с десятками URL YouTube может не опубликовать).

Лимиты YouTube: описание 5 000 знаков, комментарий 10 000 — скрипт печатает счётчики и предупреждает.

## Субтитры

- Субтитры на языке канала — доступность и SEO; файл `subtitles-<lang>.srt` делает тот же `npm run meta`
