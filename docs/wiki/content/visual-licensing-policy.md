# Визуал и лицензии

Стартовые правила — [[raw/notes/2026-11-15-kit-defaults]].

## Источники визуала

- **Собственные съёмки** — лучший материал: уникален и без вопросов по правам (`license: "own"`)
- **Свободные лицензии:** Wikimedia Commons (поиск — `npm run find-assets`), государственные архивы и агентства с открытыми лицензиями (часть материалов NASA, Library of Congress, национальных архивов — общественное достояние), стоки с бесплатной лицензией (Pexels, Pixabay — проверять условия)
- **Пресс-материалы** — только при соблюдении условий правообладателя
- **Музыка** — только с лицензией на YouTube (библиотека YouTube Audio Library, купленные треки); чужая музыка = Content ID

## Какие лицензии подходят

| Лицензия | Можно | Условие |
| --- | --- | --- |
| Public domain, CC0 | да | атрибуция по желанию (делаем всё равно) |
| CC BY | да | автор и лицензия в описании |
| CC BY-SA | да | автор и лицензия; производные — под той же лицензией |
| CC BY-NC, CC BY-ND | нет | монетизация и монтаж противоречат условиям |
| «Все права защищены», без лицензии | нет | только с письменным разрешением |

## Запрещено

- Чужие видео и фото без разрешения — риск страйков
- AI-изображения реальных людей, предметов и мест, выданные за настоящие

## Учёт

- У каждого ассета в JSON блока — `title`, `author`, `license`, `url` (`npm run check` предупреждает, если чего-то нет)
- Для каждого видео — таблица «отрезок / материал / источник / лицензия / атрибуция» в странице видео (шаблон `templates/video-template.md`)
- Атрибуция выносится в описание и закреплённый комментарий автоматически (`npm run meta`, [[wiki/content/packaging]])
