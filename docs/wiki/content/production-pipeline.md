# Производственный цикл видео

Цикл от трендов до аналитики ([[raw/notes/2026-11-15-kit-defaults]]). Частота выпусков — в [[wiki/identity/channel-concept]].

## Этапы

1. **Тренды.** n8n (если подключён) собирает данные по каналам-ориентирам в `raw/trends/`, агент переносит идеи в банк тем. Сигналы: outlier score, скорость просмотров, комментарии к выстрелившим видео, календарь дат (юбилеи, годовщины). → [[wiki/topics/topic-bank]], [[wiki/competitors/benchmark-channels]]
2. **Тема и угол.** Угол — конкретное событие или вопрос, а не «история X». Сразу 3–5 заголовков и идея превью; нет упаковки — тема слабая. → [[wiki/content/packaging]]
3. **Ресёрч и фактчекинг.** Досье, каждый факт с источником. → [[wiki/research/sources-catalog]]
4. **Сценарий.** На языке канала, вычитка человеком, разметка визуала. → [[wiki/content/script-structure]], [[wiki/content/script-checklist]]
5. **Визуал.** Собственные съёмки + открытые лицензии, таблица лицензий на видео. → [[wiki/content/visual-licensing-policy]]
6. **Озвучка.** Свой голос или синтез (ElevenLabs); заглушки macOS — для черновика монтажа.
7. **Монтаж.** Студия на Remotion в `studio/`: ролик собирается из сценария и озвучки, владелец смотрит и даёт заметки; субтитры SRT генерируются из таймлайна. → [[wiki/content/editing-studio]]
8. **Упаковка.** → [[wiki/content/packaging]]
9. **Публикация.** Перед каждой загрузкой — [[wiki/content/publish-checklist]].
10. **Аналитика.** Через 48ч и 7 дней; выводы — в банк тем и в правила сценариев. → [[wiki/metrics/kpi-and-analytics]]

Каждое видео фиксируется в журнале `wiki/videos/` по шаблону `templates/video-template.md`.

## Роли

| Задача                    | Агент           | Человек                  |
| ------------------------- | --------------- | ------------------------ |
| Сбор и анализ трендов     | ✅              | контроль                 |
| Банк тем, углы, заголовки | ✅ черновики    | финальный выбор          |
| Ресёрч и досье            | ✅              | проверка спорных фактов  |
| Сценарий                  | ✅ черновик     | вычитка                  |
| Визуал и лицензии         | ✅ поиск и учёт | съёмка, финальный отбор  |
| Озвучка                   | ✅ синтез / заглушки | свой голос или выбор голоса |
| Монтаж                    | ✅ сборка в Remotion, субтитры, главы | режиссура: заметки по таймкодам, отбор кадров |
| Описания, теги, таймкоды  | ✅              | проверка                 |
| Аналитика и выводы        | ✅ отчёт        | решения                  |

## Инструменты

- Remotion (`studio/`) — монтаж, субтитры, превью ([[wiki/content/editing-studio]])
- ElevenLabs — синтез голоса (по желанию), ключ в `studio/.env`
- n8n — сбор статистики и трендов, уведомления в Telegram (по желанию, `automation/n8n/`)
- Obsidian — чтение и правка базы знаний `docs/`
- ollama — локальная модель для рутинных проверок кадров (по желанию)
