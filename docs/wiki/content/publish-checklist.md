# Чеклист публикации видео

Проходится перед каждой публикацией ([[raw/notes/2026-11-15-kit-defaults]]).

Как пользоваться: при создании страницы видео агент копирует блок «Копия для страницы видео» в её раздел «Публикация». Галочки ставятся там, а не здесь. Правка пункта — сначала здесь, потом в страницах видео, которые ещё не вышли.

## До загрузки

Готовность ролика:

- Сценарий вычитан, ⚠️ в досье закрыты
- Голоса — финальные, не заглушки; имена, числа и термины прочитаны правильно
- Заглушек нет, `npm run check -- NNN` без предупреждений
- Хук — первые 15–30 с; заставка доигрывает ~4 с без речи
- Финал: `npm run render -- ENNN out/NNN.mp4` → `npm run finalize -- NNN` → `out/NNN-final.mp4` (1080p, −14 LUFS). Пролистать целиком: звук ровный, нет чёрных кадров и обрезанных фраз
- Права: в таблице «Визуал и лицензии» на каждый кадр есть источник и лицензия, чужой музыки нет ([[wiki/content/visual-licensing-policy]])

Упаковка ([[wiki/content/packaging]]):

- Заголовок: основной и запасной для теста, ≤ 60 знаков, ключевое слово ближе к началу, обещание видео выполняет
- Превью: 2–3 варианта для «Test & Compare»; на 240 px читаются цифра и главный предмет; не повторяют заголовок
- `description.md` → `npm run meta -- NNN`: шапка (место, эпоха, имя в первых ~150 знаках), главы (первая 0:00, каждая ≥ 10 с), источники, 3 хэштега, атрибуция; описание ≤ 5 000 знаков, комментарий ≤ 10 000
- Субтитры `subtitles-<lang>.srt` сгенерированы после последнего `timeline`
- Теги: 5–10 — тема, эпоха, люди, ключевые слова ниши
- Главы сверены с финальным файлом, а не с заглушками
- Время выхода — по плану публикаций

## Во время загрузки

- Файл назван на языке канала с ключевыми словами, превью — так же
- Сначала «Доступ по ссылке»: дождаться обработки HD, проверить Content ID и ограничения
- Заголовок, описание, теги, A/B-тест превью — перепроверить после вставки
- Язык видео и метаданных, категория
- Аудитория — «не для детей» (если это так), без лишних возрастных ограничений: они режут показы
- Синтетические голоса или лица — отметка «изменённый или синтетический контент»
- Субтитры загружены
- Плейлист назначен
- Подсказки (cards) — там, где ролик ссылается на прошлый выпуск
- Конечная заставка: последние 5–20 с, предыдущее видео + подписка; не закрывает плашку подписки и анонс
- Предпросмотр на телефоне и на ПК: превью, начало, главы
- Видимость — «Запланировано» на время из плана или «Открытый доступ»

## После публикации

В первый час:

- Видео открывается, звук и качество в норме, главы кликаются
- Ссылки в описании работают
- Закреплённый комментарий: вопрос зрителям + построчная атрибуция (`pinned-comment-<lang>.txt`)
- Первые 2 часа отвечать на комментарии
- Community-пост со ссылкой на видео

Дальше:

- Кросс-линковка: новое видео — в конечные заставки и подсказки прошлых выпусков
- Через 48 ч — метрики в таблицу страницы видео. CTR ниже ориентира ([[wiki/metrics/kpi-and-analytics]]) — сменить превью или заголовок
- Ошибки в фактах из комментариев → в досье и закреплённый комментарий
- Идеи из комментариев → [[wiki/topics/topic-bank]]
- Через 7 дней — итог: метрики, «где отваливаются», выводы в страницу видео и [[wiki/content/script-structure]]

## Копия для страницы видео

```markdown
### Чеклист публикации

По [[wiki/content/publish-checklist]].

**До загрузки**

- [ ] Сценарий вычитан, ⚠️ в досье закрыты
- [ ] Финальные голоса вместо заглушек, сомнительные чтения проверены
- [ ] Заглушек нет, `npm run check -- NNN` чистый
- [ ] Финал: `render` → `finalize` → `out/NNN-final.mp4` (1080p, −14 LUFS), просмотрен целиком
- [ ] Права: таблица «Визуал и лицензии» закрыта, чужой музыки нет
- [ ] Заголовок: основной + запасной, ≤ 60 знаков
- [ ] Превью: 2–3 варианта, читаются на 240 px
- [ ] `description.md` → `npm run meta -- NNN`: описание, главы, атрибуция, закреплённый комментарий, субтитры
- [ ] Теги 5–10
- [ ] Время выхода по плану: …

**Во время загрузки**

- [ ] Файл и превью названы с ключевыми словами
- [ ] «Доступ по ссылке» → обработка HD, Content ID чистый
- [ ] Заголовок, описание, теги, A/B-тест превью перепроверены
- [ ] Язык, категория, аудитория
- [ ] Отметка о синтетическом контенте (если есть)
- [ ] Субтитры загружены
- [ ] Плейлист: …
- [ ] Подсказки на прошлые выпуски
- [ ] Конечная заставка (5–20 с): прошлое видео + подписка
- [ ] Предпросмотр на телефоне и ПК
- [ ] Видимость: «Запланировано» / «Открытый доступ»

**После публикации**

- [ ] Видео, звук, главы, ссылки в описании работают
- [ ] Закреплённый комментарий (вопрос + атрибуция)
- [ ] Ответы на комментарии первые 2 часа
- [ ] Community-пост
- [ ] Новое видео в заставках и подсказках прошлых выпусков
- [ ] Метрики 48 ч → таблица «Метрики»; слабый CTR — сменить превью/заголовок
- [ ] Факты из комментариев → досье; идеи → банк тем
- [ ] Итог 7 дней → «Выводы»
```
