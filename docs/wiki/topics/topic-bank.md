# Банк тем

Темы для видео по рубрикам канала ([[wiki/identity/channel-concept]]). Пополняется из трендов (`raw/trends/`), комментариев зрителей, выводов после публикаций и идей владельца.

## Как оценивать

- **Потенциал** 1–5: есть ли конфликт и герой, outlier у конкурентов на похожую тему, запрос в комментариях, дата-повод
- **Упаковка:** придумываются ли 3–5 заголовков и превью. Нет — тема слабая
- **Статус:** `идея` → `в работе` (есть страница `videos/NNN-slug.md`) → `вышло` (ссылка на страницу видео) / `отложено` (причина)

Новая рубрика появляется, только если тема не подходит ни к одной существующей.
